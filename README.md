# Devlab Portfolio

Premium portfolio sajt za predstavljanje poslovnih sajtova i web aplikacija.

## Lokalno pokretanje

```bash
npm install
npm run dev
```

## Produkcijski build

```bash
npm run build
```

## Premium revizija

- jasnija hero poruka za sajtove i web aplikacije;
- predstavljanje osnivača i direktne odgovornosti;
- uklonjeni probni klijenti i lažni kontakt podaci;
- transparentno označeni pilot i razvojni projekti;
- dodata poslovna vrednost uz glavne projekte;
- precizniji paketi usluga i proces saradnje;
- unapređen kvalifikacioni kontakt upit;
- poboljšan mobilni raspored i mirnije animacije.
